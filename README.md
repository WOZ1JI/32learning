# 32learning

STM32 软硬结合学习笔记仓库（2026-09-13 起，就业冲刺 11 周计划配套）。

## 目录结构

- `每日笔记/` —— 每天一篇，文件名就是日期，如 `2026-09/2026-09-13.md`
- `模板/` —— 每日笔记模板，每天复制一份改名即可
- `错题本.md` —— 周测、练习、面试中做错或被问倒的题
- 后续随进度新增：`STM32基础/`、`接口与RTOS/`、`八股/`、`项目/` 等专题目录

## 每天怎么提交笔记

1. 在 `每日笔记/当月/` 下写当天的笔记
2. 双击桌面的 **一键提交笔记** 快捷方式（或本目录的 `一键提交笔记.bat`）
3. 想自定义说明：在 bat 后面加参数，如 `一键提交笔记.bat "GPIO八种模式"`；不加则自动用日期时间

脚本会自动完成：拉取最新 → 暂存全部更改 → 提交 → 推送到 GitHub。
没有改动时不会产生空提交；断网时提交会安全保存在本地，联网后再双击一次即可补推。
